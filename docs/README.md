# ATHENA documentation

ATHENA adds bounded cognitive control and optional tool-exposure routing to coding hosts. It is not another coding model: the host/model proposes work, Jev provides typed semantic judgments, and deterministic ATHENA policy records or enforces a decision.

## Choose a path

- **Use ATHENA:** [installation](getting-started/installation.md), [quickstart](getting-started/quickstart.md), [first session](getting-started/first-session.md)
- **Understand it:** [mental model](concepts/mental-model.md), [domains](concepts/cognitive-domains.md), [decisions](concepts/decisions.md)
- **Operate it:** [configuration](configuration/config-reference.md), [doctor](operations/doctor.md), [troubleshooting](operations/troubleshooting.md)
- **Contribute:** [repository layout](development/repository-layout.md), [testing](development/testing.md)

ATHENA defaults to observation. It does not claim correctness, safety, performance gains, or token savings.
