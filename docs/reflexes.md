# Reflexes

## Replan Lifecycle

`detected` -> `queued` -> `injected` -> `observing` -> `resolved`

After injection, ATHENA observes next meaningful action. It compares semantic strategy families rather than raw command text. Outcome is `changed`, `ignored`, or `unclear`.

AEGIS evaluates semantic relevance, unintended change, breadth, and approval need after deterministic rule bypass.

METIS evaluates action outcome and rolling semantic strategy repetition. Stagnation runs only after three relevant actions and retains six actions/results.

NIKE evaluates requirements, evidence, unresolved failures, tests, and continuation need when caller supplies a completion evaluation point.
