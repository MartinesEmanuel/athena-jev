# Glossary

**ATHENA:** cognitive control layer. **Jev:** typed semantic System 1. **Noul:** probability a proposition holds. **Score:** ordered degree. **WorldState:** bounded assessment context. **CandidateAction:** proposed next action. **AEGIS/METIS/NIKE/EPISTEMICS:** safety, progress, completion, and uncertainty domains. **Tool Router:** capability exposure optimizer. **Observe:** record without authority. **Enforce:** host applies decision. **Re-entry:** post-deliberation candidate returns to System 1.
