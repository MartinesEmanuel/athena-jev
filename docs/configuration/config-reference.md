# Configuration reference

ATHENA core config currently supports `mode` (`shadow`, `guardian`, `balanced`), `provider` (`typesafe`, `demo`), `enforcementMode` (`observe`, `enforce`), reflex booleans, policy thresholds, telemetry persistence, budgets, and `toolRouter.mode` (`off`, `observe`, `active`). Defaults are observe enforcement and observe routing. Use `athena config` for user config.
