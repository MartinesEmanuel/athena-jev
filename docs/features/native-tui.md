# Native OpenCode TUI

The V2 TUI renders a sanitized projection only: phase, cognitive domains, enforcement mode, router summary, counters, Jev latency, and last decision. Symbols are `●` GO, `◆` DELIBERATE, `◇` VERIFY, `■` BLOCK, `◈` System 2, and `!` degraded. UI failures are isolated.
