# Cognitive domains

[AEGIS](../domains/aegis.md) evaluates safety and harmful consequences. [METIS](../domains/metis.md) evaluates progress, information gain, novelty, and stagnation. [NIKE](../domains/nike.md) evaluates completion evidence and unresolved obligations. [EPISTEMICS](../domains/epistemics.md) evaluates uncertainty, context sufficiency, and contradiction.
