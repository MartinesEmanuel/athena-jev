# ATHENA v0.1.0

Give coding agents reflexes.

## Highlights

- Jev-powered semantic reflexes.
- Semantic stagnation detection.
- Risky action gating.
- Completion evidence checks.
- OpenCode integration.
- Shadow, guardian, and balanced modes.

## Known limitations

- OpenCode is only supported adapter.
- Jev thresholds remain experimental.
- No live evaluation results are committed until measured.
- Completion detection is constrained by current OpenCode hooks.
