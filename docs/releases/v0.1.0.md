# ATHENA v0.1.0

ATHENA gives coding agents reflexes.

## Features

- Universal Agent SDK
- AEGIS risk reflex
- METIS progress, stagnation, and semantic-loop reflex
- NIKE completion reflex
- TypeSafe Jev and deterministic demo providers
- OpenCode V1 and V2 adapters
- OpenAI Codex adapter
- Canonical redacted telemetry
- Semantic REPLAN lifecycle
- CLI and evaluation harness

## Verified Live Integrations

- OpenCode V1
- OpenCode V2
- OpenAI Codex

Each verified integration used real Jev and demonstrated REPLAN followed by a changed strategy. Replan entered non-user control context.

## Experimental

Cursor adapter is experimental and is not part of ATHENA v0.1 verified support. Its terminal Agent runtime did not dispatch project native hooks during live testing.

## Known Limitations

- NIKE depends on runtime completion observation hooks; no unsupported interception is claimed.
- Jev is probabilistic and never a safety guarantee.
- Comparative ATHENA-versus-baseline benchmarks are future work.
