# Changelog

All notable changes to ATHENA are documented here.

## v0.1.0 - 2026-09-21

Experimental initial public release.

### Added

- System-1 cognitive runtime with temporal state and deterministic policy.
- TypeSafe Jev integration for AEGIS, METIS, NIKE, and EPISTEMICS judgments.
- GO, DELIBERATE, VERIFY, and BLOCK decisions.
- OpenCode integration and System-2 reconsideration lifecycle.
- Local push-based cognitive HUD.
- Offline-first tests.

### Changed

- Public repository documentation and CI release preparation.

### Known limitations

- Jev adds network latency to cognitive cycles.
- Host validation is strongest for OpenCode 1.18.31.
- HUD is standalone rather than a native host sidebar.
- Performance benefits remain under evaluation.
